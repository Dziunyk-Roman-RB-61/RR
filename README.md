## Завдання № 1

**Файл:** `task1/main.c`

### Умова

Не використовуючи стандартні математичні функції (без підключення бібліотеки `<math.h>`), розрахувати суму ряду, де значення змінних `a` (`a ≥ 0`) та `N` (`N ≥ 1`) вводяться з клавіатури, `N` — ціле число:

$$S = 1 + \sum_{n=1}^{N} \frac{a^n}{a+n}$$

### Прототип функції

```c
/**
 * @brief Розраховує суму заданого ряду від n = 1 до N.
 *
 * Формула ряду: S = 1 + sum(a^n / (a + n)).
 * Степінь a^n обчислюється послідовним множенням (a^n = a^(n-1) * a),
 * тому функція pow() та бібліотека <math.h> не використовуються.
 * Оскільки результатом ділення є дробові числа, розрахунок ведеться у типі double.
 *
 * @param a Основа степеня (дійсне число, a >= 0).
 * @param N Верхня межа ряду (ціле число, N >= 1).
 * @return Сума ряду у вигляді дійсного числа подвійної точності.
 */
double calculateSeriesSum(double a, int N);
```

### Пояснення реалізації

- **Оголошення змінних та контроль введення:** у функції `main()` два цикли `do/while` перевіряють, щоб користувач ввів саме число (результат `scanf` дорівнює 1) та дотримався умов `a >= 0` і `N >= 1`. У разі введення літер або некоректних символів буфер очищається функцією `clearInputBuffer()`, що запобігає зацикленню.

```c
    do
    {
        printf("Enter the value of variable a (a >= 0): ");

        if (scanf("%lf", &a) != 1)
        {
            printf("Error: a number is required.\n");
            clearInputBuffer();
            a = -1.0;
        }
        else if (a < 0.0)
        {
            printf("Error: the value of a must be non-negative.\n");
        }
    } while (a < 0.0);
```

  Аналогічний цикл використовується для введення `N` з умовою `N < 1`.

- **Розрахунок суми ряду без математичних функцій:** обчислення винесено в окрему функцію `calculateSeriesSum()`. Змінна `power` на кожній ітерації множиться на `a`, тому `a^n` отримується без `pow()`. Для дійсного ділення значення `n` явно перетворюється до `double`.

```c
double calculateSeriesSum(double a, int N)
{
    double sum = 1.0;
    double power = 1.0;

    for (int n = 1; n <= N; n++)
    {
        power = power * a;
        sum = sum + power / (a + (double)n);
    }

    return sum;
}
```

- **Виведення результату:**

```c
    S = calculateSeriesSum(a, N);

    printf("a = %.4f, N = %d\n", a, N);
    printf("Series sum S = %.10f\n", S);
```

## Завдання № 2

**Файл:** `task2/main.c`

### Умова

Задана квадратна матриця `A` розміром `N × N`. Значення елементів матриці `A` вводяться з клавіатури. Визначити індекс стовпця, елементи якого формують найбільшу суму. Вивести на екран матрицю `A`, індекс стовпця та розраховану суму. Задачу реалізувати у вигляді окремої функції.

### Прототип функції

```c
/**
 * @brief Знаходить стовпець квадратної матриці з найбільшою сумою елементів.
 *
 * Якщо кілька стовпців мають однакову найбільшу суму,
 * повертається стовпець із найменшим індексом.
 *
 * @param A Двовимірний динамічний масив (матриця розміром N x N).
 * @param N Розмір матриці (кількість рядків і стовпців).
 * @param maxSum Вказівник на змінну, до якої записується найбільша сума.
 * @return Індекс стовпця (нумерація з нуля) з найбільшою сумою елементів.
 */
int findMaxSumColumn(double **A, int N, double *maxSum);
```

### Пояснення реалізації

- **Головна функція `main()`:** розмір `N` вводиться з перевіркою (`N >= 1`). Матриця створюється як двовимірний динамічний масив: `malloc` виділяє масив із `N` вказівників, після чого для кожного рядка виділяється пам'ять під `N` елементів. Після кожного виділення перевіряється результат на `NULL`. Наприкінці пам'ять звільняється через `free`.

```c
    A = (double **)malloc(N * sizeof(double *));

    for (int i = 0; i < N; i++)
    {
        A[i] = (double *)malloc(N * sizeof(double));
    }
```

- **Введення елементів:** кожен елемент зчитується в циклі з перевіркою результату `scanf`. У разі некоректного введення буфер очищається, і користувач вводить значення повторно.

- **Алгоритм пошуку стовпця:** функція `findMaxSumColumn()` спочатку обчислює суму нульового стовпця й вважає її найбільшою. Далі зовнішній цикл перебирає решту стовпців, внутрішній обчислює суму поточного стовпця. Якщо вона строго більша за найбільшу знайдену, оновлюються сума та індекс. Сума повертається через вказівник `maxSum`, індекс — через `return`.

```c
int findMaxSumColumn(double **A, int N, double *maxSum)
{
    int bestColumn = 0;
    double bestSum = 0.0;

    for (int i = 0; i < N; i++)
    {
        bestSum = bestSum + A[i][0];
    }

    for (int j = 1; j < N; j++)
    {
        double columnSum = 0.0;

        for (int i = 0; i < N; i++)
        {
            columnSum = columnSum + A[i][j];
        }

        if (columnSum > bestSum)
        {
            bestSum = columnSum;
            bestColumn = j;
        }
    }

    *maxSum = bestSum;

    return bestColumn;
}
```

  Початкове значення суми береться з нульового стовпця, а не дорівнює `0`. Тому алгоритм працює правильно, навіть якщо всі суми стовпців від'ємні.

- **Виведення матриці** реалізовано в окремій функції `printMatrix()`, елементи виводяться в полі шириною 9 символів із двома знаками після коми.

У ході виконання розрахункової роботи:

- реалізовано обчислення суми ряду без використання стандартних математичних функцій: степінь `a^n` отримано послідовним множенням, складність алгоритму — `O(N)`;
- закріплено навички роботи з циклами, умовними операторами та контролем коректності введених даних;
- закріплено навички роботи з функціями та передачі у функцію адреси змінної (вказівника) для повернення другого результату;
- закріплено навички роботи з двовимірними динамічними масивами: виділення та звільнення пам'яті, обхід матриці по стовпцях;
- правильність програм перевірено на тестових наборах даних, результати збігаються з ручним розрахунком.

**Обмеження.** При дуже великих значеннях `a` та `N` величина `a^n` може перевищити діапазон типу `double`, і результат стане некоректним.
